# Contributing

Issues and pull requests are welcome when they improve calculation correctness, documentation, test coverage, accessibility, or primary-source references.

For a formula change:

1. identify the affected mode, unit system, and scope;
2. link to a current primary carrier, standards-body, or tariff source;
3. add a worked example and automated test;
4. state whether the rule is universal, a preset, or contract-specific.

Please do not present a planning result as a carrier quote, engineering approval, customs decision, or safety certification.
